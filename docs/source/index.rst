Asteroids Game
==============

A clone of the classic `Asteroids <https://en.wikipedia.org/wiki/Asteroids_(video_game)>`_
arcade game built with `Python 3.13 <https://docs.python.org/3.13/>`_ and
`pygame 2.6 <https://www.pygame.org/docs/>`_.

.. code-block:: bash

   uv sync --all-groups
   uv run main.py
